## 跨系统bom一致性检验

1. 模糊查询与匹配页面，一共有四个模块，允许模糊输入项目名称生成查询对应的项目号，模糊输入工序名称查询对应的工序编码，模糊输入物料名称查询对应的物料编码，还有输入一段他人汇报的模糊语句，自动生成匹配的项目、车号、节车号和物料
2. 批量查询页面，允许查询
EAS - PBOM/工序BOM信息
EAS - 生产订单信息
EAS - 工艺路线信息
EAS - 生产备料/备料计划时序簿信息
EAS - 领料单信息
EAS - 返工订单/返工制造单信息
EAS - 生产订单变更执行记录
EAS - 物料齐套性分析
EAS - 项目计划
城轨MES - 工序BOM信息
城轨MES - 订单BOM信息 
城轨MES - 模板排程信息
城轨MES - 订单排程结果
城轨MES - 派工单信息
城轨MES - 配送需求单
城轨MES - 领料单信息
城轨MES - 返工订单信息
城轨MES - 返工制造单信息

共同的筛选条件是项目编码(字符串)、车号(正整数)、节车号(无视大小写的英文与数字集合)、工序编码(字符串)、物料编码(字符串)

对应的后端实现参考为D:\workspace\crosssystem_consistency_query_assistant\server\sql

3. 动态上下查节点图

使用类似于dify、comfyui前端的节点图、表示上文批量查询页面中提到的对应业务查询，支持将查询输出的字段作为其他查询的筛选条件来匹配，这部分需求还不明确，先寻找对应的基础库
